**Learned:**

![5T OTA circuit](../visuals/5T%20OTA%20Circuit%20Diagram.png)

```
        VDD
     |   |   |
    M3  [M4 mirror]   M3=M4 (equal W/L)
     |   |     \
     |   |      +---> OUT
  IN+ |  IN-
    M1    M2        differential pair (equal W/L)
     \    /
      [M5 tail]      sets total current ID
       |
      GND (or mirror from the bias)
```

- The M5 transistor is the tail, it is the current source.
- Differential pair of transistors at inputs (M1 and M2), IN+ and IN-:
  - If both input the same, current is the same.
  - But if there is a difference in IN+ and IN-, there will be a current difference.
  - The difference in input voltages result in a difference in current on each branch.
- The mirror, which is M4, mirrors the exact current through M3:
  - Current through M3 and M1 and M4 are the same. M3 and M1 are through the same, so same current.
  - M4 mirrors M3 which is the same as M1 current.
- Since the current through M2 is the only difference, the leftover current due to the difference in voltage flows through the output node. Due to high impedance at the node, the leftover current charges the node and becomes voltage. Due to current difference and big impedance, result in big voltage swing.
  - Small ΔV_in → small ΔI → big ΔV_out.
- M4 copies M3 because: M3 is diode connected, gate shorted to drain, M3 fixes V_gs, with the identical W/L and same V_gs, it must have the same current.

### Why used Sky130A?
As to what PDK is referring to, and why sky130A PDK is used? 
PDK: Process Design Kit
PDK bundles everything needed to design for that recipe
Used for different recipe, devices:

| | sky130 | GF180MCU | IHP SG13G2 |
|---|---|---|---|
| Who | SkyWater (US) | GlobalFoundries | IHP (Germany) |
| Node | 130 nm CMOS | 180 nm CMOS | 130 nm **BiCMOS** |
| Speciality | plain CMOS, open tapeout | plain CMOS, high voltage | SiGe HBTs, RF/mm-wave |
| Models | MOS only | MOS only | MOS **+ RF transistors** |

They differ in:  available device types, Vth values, oxide thickness (→ µCox), how many metal layers, what the models are accurate for

Found out that sky130 was chosen:
1. Tapeout: PDK that Tiny Tapeout uses, the mature route for open source route
2. It has documentation, tutorials, worked examples, more community asnwers.
3. It is available in the IIC OSIC TOOLS repo

### Xschem, insert symbol
Went to sky130_fd_pr library -> nfet_01v8 and pfet_01v8

sky130_fd_pr PDK symbols, are direct to the SPICE models in PDK. 
Netlist gets the real device model. 
So the transistors follow the real models of sky130
The vsource, gnd, vdd, lab_pin, lab_wire are devices, not real models.

- nfet_01v8 / pfet_01v8 : Normal NMOS/PMOS, 1.8V core device.
In stage 3, spec is 1.8V so 01v8 is chosen

- _lvt / _hvt suffixes: low/high thresholds flavors of the same geometry
- nfet_g5v0d10v5: thick-oxide IO device - 5V gate, 10.5V drain. For driving high voltages
- nfet3_*: 3 terminal variant (No body pin exposed)
